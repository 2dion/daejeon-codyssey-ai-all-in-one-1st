## 실행 전에

Docker 실행 환경을 준비하고 E1-1 폴더에서 미션 README의 명령을 실행합니다. macOS 실습 기록을 기준으로 하므로 다른 OS에서는 도구 옵션과 호스트 경로를 확인합니다. 검증 당시의 컨테이너 실행 상태는 현재 상태와 다를 수 있습니다.

미션의 완료·확인 여부는 E1-1 README의 체크리스트와 개별 증거를 기준으로 확인합니다. Compose 등 선택 과제는 필수 실습과 구분합니다.
